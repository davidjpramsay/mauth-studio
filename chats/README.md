# Optional Agent Work Streams

These files separate long-running Mauth work by purpose. They are not needed to install or use the app.

- `Development.md`: code, architecture, tests, documentation, and maintenance.
- `Authoring.md`: creating, converting, checking, and polishing assessments.

For development, start with `docs/current-state.md`. For assessment authoring, connect through **Help > Set Up Codex or Claude...** and work through the local Mauth tools.

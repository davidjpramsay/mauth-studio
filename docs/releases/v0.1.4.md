# Mauth Studio 0.1.4

Mauth Studio 0.1.4 is an Apple Silicon alpha release focused on complete local MCP document lifecycle support, safer agent authoring, clearer assessment editing, richer investigations, and more reliable print output.

## Download

- macOS on Apple Silicon (`arm64`)
- Developer ID signed and notarized by Apple
- Distributed as `Mauth-Studio-0.1.4-arm64.dmg`

Open the DMG, move **Mauth Studio** to Applications, then launch it from Finder, Spotlight, or the Dock. Python, Node.js, a repository checkout, and open Terminal windows are not required for teacher use or the bundled agent connector.

Existing updater-enabled builds can install 0.1.4 through **Mauth Studio > Check for Updates...** after approving the download and restart. A direct DMG install remains available.

## Included

- Sixteen bundled local MCP tools with explicit schemas, structured results, local-only annotations, and truthful error reporting
- MCP document listing, template-based saved-document creation, saved-document opening, and guarded tab closing
- Revision-aware and idempotent agent creation and close operations that use the same storage, tab, autosave, and validation systems as the human editor
- A safe default close policy that refuses unsaved work, with explicit `save` and `discard` policies when requested
- Investigation student pages with structured text sections, page-targeted diagrams, compact navigation, and an always-available teacher rubric
- A broad Editor and Inspector clarity pass, including focused diagram settings, exact-expression number fields, accessible drag controls, and compact narrow-window Inspector presentation
- Horizontally draggable document tabs that preserve active document, history, revision, and recovery state
- MathJax-rendered coordinate-axis numbers aligned to major-grid coordinates, per-axis number visibility, and left-side y-axis labels by default
- Print readiness for Plotly charts, fonts, and settled layout frames so statistical diagrams remain present in PDF output
- Document-specific A4 print margins that keep preview and printed pagination aligned, including dense one-page investigations
- Slightly more generous shared question-and-solution line rhythm for display-size fractions without stored-document migration
- Updated test, exam, notes, and investigation template presentation plus cleaner website examples
- A refined portrait `.mauth` Finder icon and read-only Spacebar Quick Look summary without inconsistent third-party thumbnails
- Platform-neutral desktop runtime, application-data, executable-name, and native folder-dialog seams in preparation for future Windows work

## Agent Setup

1. Keep Mauth Studio in Applications and open it.
2. Choose **Help > Set Up Codex or Claude...**.
3. Copy and run the command for Codex or Claude Code, or merge the shown `mauth` entry into Claude Desktop's Developer configuration.
4. Keep Mauth Studio open while the agent uses its Mauth tools.

The connector is contained inside Mauth Studio and discovers the running app through a private per-launch local manifest. Users do not copy bridge tokens or download separate agent files.

## Release Safety

- Mauth does not download or install updates without teacher confirmation.
- The updater is enabled only in packaged releases with signed update metadata.
- Development builds do not check for updates.
- Packaging verification checks nested Quick Look signatures, the bundled connector, updater metadata, and Gatekeeper acceptance.
- Publication remains draft-first until the DMG, ZIP, updater metadata, and ZIP blockmap pass remote verification.

## Alpha Limitations

- Apple Silicon only; Intel and universal builds are not currently supplied.
- Quick Look shows a native document summary rather than the complete rendered assessment pages.
- Windows and Linux packages are not yet distributed.
- This is early software. Use **Backup ZIP** regularly and keep important assessment files in a backed-up folder.
- Codex, Claude Code, or Claude Desktop must be installed separately if agent integration is wanted.

## Development

Use `pnpm desktop:dev` for source iteration. Use `pnpm smoke:agent-connector` for focused connector verification. `pnpm macos:release` and `pnpm macos:ship` remain reserved for traceable external releases.

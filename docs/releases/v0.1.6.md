# Mauth Studio 0.1.6

Mauth Studio 0.1.6 is an Apple Silicon alpha release focused on diagram authoring, readable graph labels, safer document handling, and reliable printing.

## Installation And Updates

- macOS on Apple Silicon (`arm64`) only.
- Developer ID signed and notarized by Apple through the guarded release workflow.
- Download `Mauth-Studio-0.1.6-arm64.dmg`, or use **Mauth Studio > Check for Updates...** in an updater-enabled installed app.
- Downloads and installation require your approval. Save your work before restarting to update.
- Python, Node.js, and a repository checkout are not required.

## Changes

- Ordinary graph labels use the document body font while mathematical labels retain MathJax. Existing prose labels update without document migration.
- Coordinate and vector graphs retain a small frame margin even with axis names and numbers hidden, reducing clipped labels without changing authored coordinates.
- Updated stacked-column guidance gives labels room and centres them within their own percentage segments, while preserving data and deliberate teacher choices.
- The authoring workflow keeps the installed app as the primary workspace and makes isolated browser verification explicit.
- Repeated Student/Solutions printing releases graph listeners correctly, and pending camera saves no longer interrupt a 3D rotation.
- Diagram labels support dragging, reset, Undo/Redo and persistence across hidden solution layers; native Penrose geometry validates constraints and preserves mathematical relationships during resampling.
- Stronger mathematical-expression bounds, authenticated local services, safer backup imports and SVG sanitization protect the local authoring boundary.
- Native Open and Save As dialogs, Open Recent, and Show in Finder replace the desktop Files drawer for ordinary document opening and saving.
- Each tab retains its own folder and save destination. Save As protects against overwriting another open tab or a file changed outside Mauth.
- Backup, restore, and version history remain available from the File menu.
- Faster startup uses a pre-expanded Python service, a lightweight health check, and an immediate loading window.
- Fresh installations start with an empty document, and Command-W closes the current tab before the window.
- Cloud-folder failures identify the requested document and offer retry guidance without replacing unsaved recovered work.
- Stronger revision checks, independent recovery backups, and safer cold-start and already-running file opening preserve document ownership.
- Printing waits for diagrams and fonts, reports readiness failures, and prevents hidden solution content from shrinking Student PDFs.
- Statistical charts gain structured probability-region shading and clearer axis ticks; coordinate graphs have improved label spacing.
- MCP requests recover from late timeout acknowledgements, with clearer lifecycle errors and structured action contracts.
- Updated diagram answer-space and marking guidance avoids redundant working areas beneath completed diagrams.

## Known Limitations

- This is alpha software. Keep important assessments backed up.
- Intel Macs, Windows, and Linux packages are not supplied.
- Cloud files must be available locally; Mauth does not force potentially blocking downloads from Google Drive or other providers.
- Long visible mathematical expressions may still need teacher-controlled line breaks before printing.
- Native picker interaction, clean-machine installation, and an update from 0.1.5 require manual verification; automated tests do not certify these workflows.
- Quick Look provides a document summary, not a complete assessment preview.

The bundled agent connector remains optional. Configure it through **Help > Set Up Codex or Claude...**.

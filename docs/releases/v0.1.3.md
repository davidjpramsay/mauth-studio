# Mauth Studio 0.1.3

Mauth Studio 0.1.3 is an Apple Silicon alpha release focused on multi-document work, native macOS integration, clearer desktop controls, and safer reusable-logo cleanup.

## Download

- macOS on Apple Silicon (`arm64`)
- Developer ID signed and notarized by Apple
- Distributed as `Mauth-Studio-0.1.3-arm64.dmg`

Open the DMG, move **Mauth Studio** to Applications, then launch it from Finder, Spotlight, or the Dock. Python, Node.js, a repository checkout, and open Terminal windows are not required for teacher use or the bundled agent connector.

Existing updater-enabled builds can install 0.1.3 through **Mauth Studio > Check for Updates...** after approving the download and restart. A direct DMG install remains available.

## Included

- Multiple open documents in one shrinkable, horizontally scrollable tab rail
- Independent document history, save state, revision state, crash recovery, and guarded close behavior per tab
- Explicit `documentId` targeting for Codex and Claude snapshot, action, preview, and validation tools
- Native `.mauth` Finder identity, dedicated document artwork, generated thumbnails, and a read-only Spacebar Quick Look summary
- Sharper layout-scaled A4 screen preview without changing printed dimensions
- Native macOS menu commands for System Status, light/dark appearance, and solution validation
- A single compact Student/Solutions mode toggle and additional toolbar space for document tabs
- Readable System Status controls in both app themes with automated contrast coverage
- Reusable-logo reconciliation that renames the legacy Grace entry to **Grace Christian College**, removes identical legacy `Grace Logo Only` copies, and safely remaps old embedded logo ids
- The self-contained Codex and Claude MCP connector introduced in 0.1.2
- ZIP-only updater metadata that matches the exact published update bytes; the notarized DMG remains the direct installer
- Existing tests, exams, worksheets, notes, investigations, diagrams, manual solution layers, storage, backup, print, and update workflows

## Agent Setup

1. Keep Mauth Studio in Applications and open it.
2. Choose **Help > Set Up Codex or Claude...**.
3. Copy and run the command for Codex or Claude Code, or merge the shown `mauth` entry into Claude Desktop's Developer configuration.
4. Keep Mauth Studio open while the agent uses its Mauth tools.

The packaged setup path points to the connector inside that user's installed Mauth Studio app. Development builds may instead show the current source-repository path. Neither path is copied from the developer's Mac into another user's installation.

## Release Safety

- Mauth does not download or install updates without teacher confirmation.
- The updater is enabled only in packaged releases with signed update metadata.
- Development builds do not check for updates.
- Packaging verification checks nested Quick Look signatures, the bundled connector, updater metadata, and Gatekeeper acceptance.
- Publication remains draft-first until the DMG, ZIP, updater metadata, and ZIP blockmap pass remote verification.

## Alpha Limitations

- Apple Silicon only; Intel and universal builds are not currently supplied.
- Quick Look shows a native document summary rather than the complete rendered assessment pages.
- This is early software. Use **Backup ZIP** regularly and keep important assessment files in a backed-up folder.
- Codex, Claude Code, or Claude Desktop must be installed separately if that agent integration is wanted.

## Development

Use `pnpm macos:dev` for source iteration. Use `pnpm smoke:document-tabs` and `pnpm smoke:agent-connector` for focused verification. `pnpm macos:release` and `pnpm macos:ship` remain reserved for traceable external releases.

# Mauth Studio 0.1.5

Mauth Studio 0.1.5 is an Apple Silicon alpha release focused on clearer teacher-controlled authoring, more faithful 3D mathematical diagrams, first-class formula sheets, and a more resilient local MCP connection for Codex and Claude.

## Download

- macOS on Apple Silicon (`arm64`)
- Developer ID signed and notarized by Apple
- Distributed as `Mauth-Studio-0.1.5-arm64.dmg`

Open the DMG, move **Mauth Studio** to Applications, then launch it from Finder, Spotlight, or the Dock. Python, Node.js, a repository checkout, and open Terminal windows are not required for teacher use or the bundled agent connector.

Existing updater-enabled builds can install 0.1.5 through **Mauth Studio > Check for Updates...** after approving the download and restart. A direct DMG install remains available.

## Included

- A responsive **Content / Settings** authoring workspace that uses the available width without shrinking controls to unreadable sizes
- Compact and narrow-window modes that switch between Content and Settings while preserving a usable A4 preview
- Pane-aware preview zoom and a full-width editor surface for more predictable work on 13-inch displays
- First-class standard-test formula sheets with dedicated **F** navigation, editing, preview, print, undo, and Student/Solutions support
- One structured wording owner for ordinary question, part, and subpart stems, plus validation for redundant leading text blocks
- More reliable selection and editing of later question parts, nested content, and renderer-specific diagram elements
- A controlled school-logo selector with aligned text, keyboard navigation, and consistent macOS presentation
- Sharper title-page and print typography, compact name/result rows, square-ended coloured accent rails, and corrected document-specific print margins
- Textbook-style 3D solids with equal-scale projection, live camera-safe silhouettes, restrained surface rendering, and independently adjustable object/frame size
- Correct joined cone and spherical-cap surfaces with shared geometry, depth ordering, hidden internal faces, one closed seam, and rotation-safe rendering
- Non-draggable 3D faces while retaining camera rotation and independently draggable labels
- Draggable 2D and 3D labels with persistent offsets and explicit reset controls
- Discoverable **Annotations** for dimension-to-dimension and dimension-to-face perpendicular relationships
- Shrink-wrapped diagram selection outlines that no longer claim unused page width
- Graph-number, axis-label, and function-boundary refinements aligned with Mauth's diagram authoring rules
- MCP runtime rediscovery and one bounded retry across app relaunches or per-launch token rotation
- Packaged-renderer API authentication and background-safe lifecycle acknowledgement without exposing bridge credentials
- Recursive snapshot mark totals and stronger structured diagram, wording, and authoring validation
- Updated agent rules, bridge/action documentation, AI brains, tests, and smoke coverage for the shipped behavior

## Agent Setup

1. Keep Mauth Studio in Applications and open it.
2. Choose **Help > Set Up Codex or Claude...**.
3. Copy and run the command for Codex or Claude Code, or merge the shown `mauth` entry into Claude Desktop's Developer configuration.
4. Keep Mauth Studio open while the agent uses its Mauth tools.

The connector is contained inside Mauth Studio and discovers the running app through a private per-launch local manifest. Users do not copy bridge tokens or download separate agent files.

## Release Safety

- Mauth does not download or install updates without teacher confirmation.
- The updater is enabled only in packaged releases with signed update metadata.
- Development builds do not check for updates.
- Packaging verification checks nested Quick Look signatures, the bundled connector, updater metadata, Gatekeeper acceptance, and remote release asset integrity.
- Publication remains draft-first until the DMG, ZIP, updater metadata, and ZIP blockmap pass remote verification.

## Alpha Limitations

- Apple Silicon only; Intel and universal builds are not currently supplied.
- Quick Look shows a native document summary rather than the complete rendered assessment pages.
- Windows and Linux packages are not yet distributed.
- This is early software. Use **Backup ZIP** regularly and keep important assessment files in a backed-up folder.
- Codex, Claude Code, or Claude Desktop must be installed separately if agent integration is wanted.

## Development

Use `pnpm desktop:dev` for source iteration. Use the focused editor, graph3d, and connector smokes for runtime verification. `pnpm macos:release` and `pnpm macos:ship` remain reserved for traceable external releases.

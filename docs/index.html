What is Mauth Studio?

Mauth Studio is a work-in-progress tool for teachers who make maths assessments. The app shows printable A4 pages in the same window where you edit questions, diagrams, tables, and solutions. When you want help, a connected agent can create content, fix layout, improve diagrams, and check the rendered result.

teacher edits and reviews -> optional agent uses structured local tools

For teachers

Build printable maths tests, exams, and worksheets with title pages, questions, diagrams, tables, working space, and solutions.

  • Preview before print: see the A4 pages directly in Mauth Studio.
  • Keep files local: choose where your visible documents live, with autosave, logos, and versions on your Mac.
  • Ask for help: Codex or Claude can help write, edit, check, and improve assessments.

Optional agent help

Mauth works on its own. When you want help, Codex or Claude can use the app's structured local tools.

  • Write and revise: create questions, solutions, tables, and diagrams.
  • Check: validate structure and inspect Student and Solutions views.
  • Stay local: the connector talks to the Mauth app running on your Mac.

Install

Open the downloaded DMG, move Mauth Studio to Applications, then launch it from Finder, Spotlight, or the Dock.

  • Platform: macOS on Apple Silicon.
  • Trust: Developer ID signed, notarized, and Gatekeeper-validated.
  • Updates: Mauth asks before downloading and again before restarting to install.
  • Agents: the signed app includes its own Codex and Claude MCP connector.
  • Stage: alpha software intended for early testing and feedback.

Connect an agent, if you want one.

Mauth works without AI. MCP is simply the local connection that lets Codex or Claude use structured Mauth tools. The connector is already inside the signed app.

You do not need to paste a setup prompt, find a token, clone the repository, or download agent files.

“Inspect the open Mauth assessment, fix its formatting, validate it, and check both previews.”
  1. Open Mauth Studio.
  2. Choose Help > Set Up Codex or Claude...
  3. Copy and run the one-time setup for your agent.
  4. Keep Mauth open, then ask the agent for the assessment work you need.
